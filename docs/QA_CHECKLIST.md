# 공개 전 수동 검사표

## 공통

- [ ] 홈에서 3번 이내 클릭으로 12개 계산기에 도착한다.
- [ ] 모든 계산기에서 정상값·경계값·잘못된 값을 각각 시험한다.
- [ ] 오류 뒤 올바른 값을 넣으면 결과가 정상으로 바뀐다.
- [ ] 낮·밤 전환 후 새로고침해도 선택이 유지된다.
- [ ] 홈 검색과 전체 계산기 검색이 작동한다.
- [ ] 소개·문의·개인정보·약관·404가 열린다.
- [ ] 잘못된 주소에서 404와 홈 버튼이 보인다.

## 화면과 접근성

- [ ] 360px, 768px, 1200px에서 가로 스크롤이 없다.
- [ ] 키보드 Tab·Shift+Tab·Enter·Space로 메뉴와 계산을 사용할 수 있다.
- [ ] 포커스 테두리가 낮·밤 모두 보인다.
- [ ] 200% 확대에서 버튼·결과가 겹치지 않는다.
- [ ] 모션 감소 설정에서 불필요한 움직임이 사라진다.
- [ ] 실제 Android Chrome과 가능한 iPhone Safari에서 확인한다.

## 자동검사

```powershell
npm.cmd run typecheck
npm.cmd test
npm.cmd run test:e2e:desktop
npm.cmd run build
npm.cmd run validate:build
```
